# PitPitch

**足球与 F1，一个应用掌握赛程、比分和积分。**

PitPitch 是一款 Android 赛事信息应用，支持七项欧洲足球赛事与 F1。查看下一场比赛、回看历史成绩、了解球队阵容，或为想看的比赛设置开赛提醒。白色界面配合紧凑列表，已归档的数据支持离线浏览。

[下载 Android 安装包](https://github.com/cgl-sd/PitPitch/releases/download/v0.7.5/PitPitch-0.7.5.apk) · [版本与校验文件](https://github.com/cgl-sd/PitPitch/releases/tag/v0.7.5)

当前版本：**0.7.5** · 系统要求：**Android 8.0 及以上**

## 赛事尽在首页

首页集中展示你选择的赛事，默认开启英超、欧冠和 F1。足球按真实轮次预览接下来的比赛，F1 展示分站现场图片与练习、排位和正赛时间，赛事卡片按下一场时间排序。

点击比赛查看详情，点击足球卡片空白处进入完整赛程。底栏可在首页、足球与 F1 之间切换，右侧主队队徽直达球队主页；主队默认为曼联，可在设置中更换。

## 足球：从赛程到首发

支持 **英超、西甲、意甲、德甲、法甲、欧冠、欧联**，历史数据从 **2020/21 赛季**起保留。

- **完整赛程**：连续浏览所选赛事和赛季，默认定位下一场比赛，也可通过轮次按钮跳转。欧战支持联赛阶段（旧赛制为小组赛）与淘汰赛。
- **积分榜**：查看名次、球队、积分和可确认的资格或降级标识，并了解对应赛季的基本计分、同分排序与晋级规则。
- **球员榜单**：在进球榜与助攻榜之间切换，查看来源已公布的统计。
- **比赛详情**：查看比分、比赛状态、技术统计、进球与红牌等重要事件，以及已发布的首发和阵型。点击双方队徽可进入球队主页。
- **球队主页**：以球队主色和队徽呈现，提供所属国内联赛排名、赛季完整赛程和分位置队员名单。

球员姓名使用 ESPN 原始英文全名，不显示球员照片；球队和球场优先使用经过核验的中文常用名，无法唯一确认时保留原名。对阵或场地尚未公布时显示“待定”，缺失数据保持未知。

## F1：周末安排与赛季排名

支持 **2020 赛季起**的赛历、分站成绩及年度积分。

- **全年赛程**：按真实站次浏览，当前赛季默认定位当日或下一站，历史赛季从第一站开始。
- **比赛周末**：展示已公布的练习、排位、冲刺和正赛时间。界面只展示一次练习，优先采用第一次真实练习。
- **分站成绩**：排位显示供应商名次及最后参加阶段的圈速；正赛保留完整名次、结果与本站积分，包括退赛、未发车和零分车手。
- **年度积分**：查看车手与车队排名、对应赛季图片和队色，以及依据已发布积分轮次计算的赛季进度。
- **分站图片**：首页使用现场图片，赛程与详情提供按赛道和历史布局绑定的赛道轮廓。

## 开赛前五分钟提醒

点击比赛旁的铃铛即可预约应用通知，再次点击取消。提醒在真实开赛时间前 **5 分钟**触发，所有时间按设备时区显示。

预约时会按需申请通知和精确提醒权限；没有真实开赛时间或提醒时间已经过去的比赛不能新建预约。提醒保存在当前设备，覆盖升级后保留，设备重启后恢复未来有效提醒。强行停止应用、撤销权限或厂商省电策略可能影响通知投递。

应用不读写系统日历。此前版本已创建的日历事件由系统日历管理，不会自动删除。

## 离线浏览与更新

赛程、历史成绩及已打包图片优先从本地读取。打开应用后会在本地内容呈现后后台刷新；点击底栏当前页面图标也可刷新全部赛事数据。进入足球积分栏目或切换其中的赛事、赛季时，会单独更新对应积分榜。网络失败时保留已有有效内容。

设置中的 **“检查更新”** 用于检查本仓库的正式 Release。确认下载后，应用核验安装包的 SHA-256、大小、包名、版本和签名身份，再交给 Android 系统安装器，由你确认安装。访问更新需要设备能连接 GitHub 及其文件托管域名。

### 安装方式

1. 从上方链接下载 `PitPitch-0.7.5.apk`。
2. 按 Android 提示允许当前下载来源安装应用，并确认安装。
3. 已安装旧版本时直接覆盖安装，保留偏好与本地数据，无需卸载。

Release 同时提供 `PitPitch-0.7.5.apk.sha256`，可用于核对下载文件。当前安装包沿用既有本机签名证书，以兼容已有安装；尚未上架应用商店。

## 数据来源与使用范围

| 内容 | 主要来源 |
| --- | --- |
| 足球赛程、比分、积分、球员及比赛详情 | ESPN 公开端点 |
| 足球补充轮次 | OpenFootball、FixtureDownload |
| 球队和球场中文显示资料 | Wikidata 实体标签及逐条人工核验的中文体育媒体常用名 |
| F1 赛程、排位、正赛与年度积分 | Jolpica |
| 队徽、人物、赛车、现场及赛道图片 | 随资产保留的原始来源与署名索引 |

历史范围固定从足球 2020/21、F1 2020 起至当前赛季，新增年份不会滑动删除 2020 年。当前赛季内容取决于来源已经公布的资料。

PitPitch 提供本地真实归档和网络缓存，**不是官方授权应用，也不是秒级直播、F1 遥测或官方稳定 API 服务**。历史首发、部分统计、时段和图片可能缺失；应用不预测首发，不生成比分、轮次或积分，也不按部分赛程推算官方排名。联赛杯、足总杯目前未接入，身价和未经核验的教练信息不展示。

## 隐私与图片许可

应用没有账号系统。主队和首页赛事选择保存在本地；普通偏好可参与 Android 系统备份，可重建的数据库与网络缓存不参与备份。提醒及下载关联为设备局部数据，不随备份迁移，覆盖升级仍保留。

赛事刷新会访问对应数据端点。已打包图片优先本地读取；新出现、尚未打包的队徽可能从供应商原始 HTTPS 地址加载并缓存，托管方会收到 IP 地址等正常网络请求信息。足球球员头像不在界面请求。检查和下载安装更新时会访问 GitHub。

球队、赛事商标及图片的权利属于各权利人，公开访问不等于获得开源许可，也不代表官方合作。资源的作者、来源、许可与修改说明随资产保留：

- OpenFootball 与 Wikidata 结构化资料采用 CC0；FixtureDownload 补充资料保留来源记录。
- 赛道参考地图使用 [bacinger/f1-circuits](https://github.com/bacinger/f1-circuits)（MIT）；历史布局补充采用 Wikimedia Commons 已许可原图，按赛季和站次关联。逐项作者、来源、修改说明和 SHA-256 见 `app/src/main/assets/f1-media/outline-attributions.json`，CC BY-SA 3.0/4.0 等许可原文随包保留。
- 启动字标使用的 Roboto 字形保留 SIL Open Font License。其他图片以各自来源和许可记录为准，不能将本仓库中的图片或商标视作可自由再分发的素材。

## 开发与构建

项目采用 **Kotlin、Jetpack Compose、Material 3、Navigation Compose、ViewModel + StateFlow、Room 和 DataStore**。界面通过 Repository 读取统一的本地模型；打包归档和网络缓存进入同一数据层，数据库升级通过 Migration 保留数据。

工具链：JDK 17、Gradle 8.9、AGP 8.7.3、Kotlin 2.0.21、Android compile/target SDK 35，最低 API 26。

使用 Android Studio 打开项目根目录，将 Gradle JDK 设为 17，并通过本机 `local.properties` 或 `ANDROID_HOME` 配置 Android SDK。依赖已缓存时可离线构建：

```bash
./gradlew --offline :app:assembleDebug :app:testDebugUnitTest
```

Debug APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。设备调试使用 Android Studio 的 Running Devices；测试源码位于 `tmp/tests/unit/java` 和 `tmp/tests/android`，由 Gradle sourceSets 接入。

```bash
./gradlew --offline :app:assembleRelease
```

Release 默认生成未签名 APK。需要自动签名时，在本机创建不纳入 Git 的 `keystore.properties`，配置 `storeFile`、`storePassword`、`keyAlias`、`keyPassword`；更新安装包必须保持包名与签名证书一致。自行构建的包能否覆盖已有安装取决于证书，不能通过卸载规避数据保留要求。

普通 Gradle 构建不会联网抓取赛事资料。数据整理工具位于 `app/data-tools` 与 `tmp/tests`，修改归档后使用 `build_local_backend_manifest.py --verify` 和相应核验脚本检查来源、哈希与范围。

当前版本已通过本地 Debug/Release 构建、74 项单元测试及 Studio 模拟器图标与覆盖安装烟测。尚未完成真机和跨版本设备矩阵、完整无障碍人工验收、OEM 省电与云备份恢复测试；模拟器结果不代表所有设备均已验证。
